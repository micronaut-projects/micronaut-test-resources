Infinispan support

Infinispan support will automatically start an Infinispan container and provide the values of the `infinispan.client.hotrod.server.host` and `infinispan.client.hotrod.server.port` properties.

The default image (`{default-image-infinispan}`) can be overwritten by setting the `test-resources.containers.infinispan.image-name` property.
The default version can be overwritten by setting the `test-resources.containers.infinispan.image-tag` property.

Resolved properties:

[[infinispan-client-hotrod-server-host]]
`infinispan.client.hotrod.server.host`:: The host of the Infinispan server

[[infinispan-client-hotrod-server-port]]
`infinispan.client.hotrod.server.port`:: The port of the Infinispan server (Hot Rod protocol, 11222)

[[infinispan-client-hotrod-username]]
`infinispan.client.hotrod.security.authentication.username`:: Username for Hot Rod authentication (if configured in container)

[[infinispan-client-hotrod-password]]
`infinispan.client.hotrod.security.authentication.password`:: Password for Hot Rod authentication (if configured in container)

See the link:https://testcontainers.com/modules/infinispan/[Testcontainers Infinispan module] for more information.
